# Python 101 Final Project

## In Memory only CLI Task Manager

This is a simple program with a basic menu that lets the user select 1 of 7 options to perform in memory only. Option 7 will only work with the appropriate API key and the menu will update dynamically based upon the key existing or not. The actual validity of the key is not checked, only that it exists.


This may be expanded in the future as a fun project to include persistent storage using SupaBase (See the Supabase branch for the beginnings of that) and other features to include modification, and eventually shift out into a GUI likely using TKinterCustom.
